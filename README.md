# JobTalk AI

AI-powered PWA email client unifying Gmail, O365, and IMAP.

## Tech Stack
- Node.js (v20 LTS)
- React 19
- React Router v7 + Remix-PWA
- Vanilla CSS
- Dexie.js (Local-First DB)

## Getting Started

1. Restore the environment:
```bash
nvm use && npm install
```

2. Start the development server:
```bash
npm run dev
```

For architectural decisions, please refer to [ARCHITECTURE.md](docs/ARCHITECTURE.md).
